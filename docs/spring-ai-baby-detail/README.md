# Spring AI 宝宝级细讲教程

这是一套比 `docs/spring-ai-baby/` 更细的教程。

上一套更像路线图。  
这一套更像：

- 这个字段是干什么的
- 这个方法为什么存在
- 这个注解起什么作用
- 这一行代码为什么要这样写

如果你现在的感觉是：

`我知道大概做了什么，但我还是不会自己一点点写出来`

那你应该看这一套。

## 这套教程的特点

### 特点 1：直接对着你现在的代码讲

不会写成脱离项目的假教程。

### 特点 2：解释字段、方法、注解

比如会讲：

- `@RestController` 为什么要加
- `@Valid` 为什么会拦截空参数
- `AiChatResponse` 每个字段谁来填
- `AiPromptPlan` 为什么不是一个普通字符串

### 特点 3：每章都有“你自己现在就能做的小练习”

不是让你全部重写，而是让你一点点试着复刻。

## 你现在要记住一句话

这套文档不是为了让你“读懂”。

而是为了让你：

`一边看，一边对照代码，一边自己试着改一点点。`
